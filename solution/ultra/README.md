# Ultralytics pipeline (YOLO26 / YOLO11 / RT-DETR)

Egocentric EgoObjects detector training and COCO-results inference. Shared conventions: `../CONVENTIONS.md`.

## Data

Yamls point at **clipped** YOLO labels under `solution/data/yolo/` (regenerated by `tools/prepare_data.py --yolo-dir`):

- `data/ego_train.yaml` — train 10000 / val 1000
- `data/ego_trainval.yaml` — train 11000 (train+val) / val 1000 (metrics optimistic; final model only)

Official `resource/data/labels` are **not clipped**; Ultralytics would drop 12 train + 2 val images as corrupt. Images under `solution/data/yolo/images/` are per-file symlinks into `resource/data/images/`. Label `*.cache` / disk `*.npy` are redirected to `work_dirs/ultra/_cache/` (never written into `resource/`).

## Train

```bash
cd /home/zhangyuming/Egoobjection/solution
export YOLO_AUTOINSTALL=False
export CUDA_VISIBLE_DEVICES=3   # always set explicitly

# defaults: AdamW (YOLO lr0=1e-3 wd=5e-4; RT-DETR lr0=1e-4 wd=1e-4), cos_lr, warmup=2,
# close_mosaic=min(10,epochs//6), amp, cache=ram, workers=12, seed=0
python ultra/train.py --model yolo26x.pt --imgsz 1024 --epochs 80 --batch 8 \
  --data ultra/data/ego_train.yaml --name y26x_1024_train

# RT-DETR
python ultra/train.py --model rtdetr-x.pt --imgsz 1024 --epochs 60 --batch 8 --name rtdetrx_1024

# throughput probe (exits after N measured iters)
python ultra/train.py --model yolo26x.pt --imgsz 1024 --batch 8 --bench-iters 40
```

Prepared 80-epoch launchers (do not start from an agent without asking):

```bash
CUDA_VISIBLE_DEVICES=3 bash ultra/run_y26x_1024_train.sh
CUDA_VISIBLE_DEVICES=3 bash ultra/run_y26x_1024_trainval.sh
```

Both set `patience=1000`, `save_period=5`, `cache=ram`, `workers=12`, and tee stdout to `solution/logs/`. Extra `key=value` overrides can be appended.

## Predict / eval

Writes a flat COCO results json (original-pixel clipped xywh, ≤100 dets/image, conf 0.001):

```bash
CUDA_VISIBLE_DEVICES=3 python ultra/predict_coco.py \
  --weights work_dirs/ultra/<run>/weights/best.pt --split val --eval [--imgsz 1024]

# TTA (YOLO NMS heads only; RT-DETR / YOLO26 --nms false → warned and disabled)
CUDA_VISIBLE_DEVICES=3 python ultra/predict_coco.py \
  --weights work_dirs/ultra/<run>/weights/best.pt --split val --eval --augment

# YOLO26 head: default/true = one-to-many + NMS; false = end-to-end one-to-one
CUDA_VISIBLE_DEVICES=3 python ultra/predict_coco.py ... --nms false

# shared pycocotools wrapper (same as resource/eval.py)
python tools/coco_eval.py --gt /home/zhangyuming/Egoobjection/resource/data/val.json \
  --pred work_dirs/ultra/preds/<tag>.json
```

## Benchmarks (1× RTX 4090, AMP, `cache=ram`)

| model | imgsz | batch | min/epoch | peak VRAM |
|---|---:|---:|---:|---:|
| yolo26x | 1024 | 8 | ~5.6 | ~20.5 GB |
| yolo26x | 1280 | 4 | ~9.3 | — |
| yolo11x | 1024 | 8 | ~5.0 | — |
| rtdetr-x | 1024 | 8 | ~7.3 | — |

80 epochs × yolo26x@1024 b8 ≈ **7.5 h** wall (plus val). Prefer fixed batch; AutoBatch after OOM is unreliable.

## Pitfalls

- Always set `CUDA_VISIBLE_DEVICES` (`train.py` / `predict_coco.py` refuse otherwise). Set `YOLO_AUTOINSTALL=False`.
- Do not use `resource/data/labels` — use `solution/data/yolo` (clipped). Official COCO GT stays unclipped for scoring.
- `optimizer='auto'` switches AdamW → MuSGD after ~10k steps; `train.py` sets AdamW explicitly.
- Ultralytics `half` is `quantize=16` in 8.4.160; `predict_coco.py --half` maps that.
- YOLO26 (8.4.160): default head is one-to-many + NMS; `--nms false` is the NMS-free one-to-one head (usually lower AP here).
- RT-DETR has no Ultralytics TTA path; `--augment` is ignored with a warning.
- `cache=ram` needs ~18 GB host RAM at 1024 for the resized train set; first epoch still pays JPEG decode.
- trainval val mAP is leaked — pick the submission checkpoint by epoch / held-out protocol, not best.pt from trainval.
- DDP untested in this checkout (only one free GPU during bring-up).
