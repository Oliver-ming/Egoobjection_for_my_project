# 数据集说明

## 资源目录概览

本目录包含 2D 目标检测项目所需的核心资源，包括数据集、评估工具与模型配置。

### 目录结构

```
resource/
├── data/       # 数据集文件与配置
├── mm/         # MMDetection 框架实现
├── eval.py     # COCO 风格评估脚本
└── README.md   # 说明文档
```

## 数据集（data/）

`data/` 目录包含 EgoObjects 数据集的子集，用于第一人称视角目标检测。

- **类别数**：10 个预定义物体类别
- **标注格式**：COCO 风格 JSON
- **类别列表**：Pillow、Box、Book、Bottle、Chair、Mug、Door、Shelf、Plate、Sofa

### 数据集结构

```
data/
├── images/
│   ├── train/        # 10,000 张训练图像
│   ├── val/          # 1,000 张验证图像
│   └── test/         # 2,000 张测试图像
├── labels/           # 自动生成的 YOLO 格式标签
├── train.json        # 训练集 COCO 标注
├── val.json          # 验证集 COCO 标注
├── test.json         # 测试集元数据（无标签）
└── dataset.yaml      # YOLO 数据集配置
```

### 数据集配置（dataset.yaml）

`dataset.yaml` 用于：

- 定义 10 个物体类别
- 指定 YOLO 训练所用的数据集路径
- 兼容 Ultralytics 框架

## MMDetection 框架（mm/）

`mm/` 目录包含基于 MMDetection 的完整实现，用于训练与评估高级目标检测模型。

### 配置文件（mm/config/）

| 文件 | 说明 |
|------|------|
| `data.py` | 数据集配置与数据处理流水线 |
| `default_runtime.py` | 运行时设置与 hooks |
| `faster-rcnn_r50_fpn_giou_20e.py` | Faster R-CNN 配置 |
| `deformable-detr_r50.py` | Deformable DETR 配置 |
| `schedule_20e.py` | 训练调度设置 |

### 工具（mm/tools/）

`tools` 目录包含：

- 训练脚本：`train.py`、`dist_train.sh`
- 测试脚本：`test.py`、`dist_test.sh`
- 模型评估与分析工具
- 数据集转换器
- 部署工具

### 数据集可视化（mm/browse_dataset.py）

浏览数据集并可视化标注：

```bash
cd mm
python browse_dataset.py \
  config/faster-rcnn_r50_fpn_giou_20e.py \
  --output-dir vis
```

## 评估工具（eval.py）

`eval.py` 提供 COCO 风格评估，用于衡量模型性能。

### 功能

- 标准 COCO 指标：AP@0.5、AP@0.75、AP@0.5:0.95
- 按类别分析性能
- 支持多种 IoU 类型：边界框、分割掩码、关键点
- 提交格式校验

### 用法

```bash
python eval.py \
  --gt data/val.json \
  --pred path/to/predictions.json \
  --per-class
```

### 参数

| 参数 | 说明 |
|------|------|
| `--gt` | 真值 COCO JSON 文件路径 |
| `--pred` | 预测结果 JSON 文件路径 |
| `--types` | 评估的 IoU 类型，默认为 `bbox` |
| `--per-class` | 输出每个类别的 AP 分数 |

### 预测格式

评估脚本要求预测结果为 COCO 格式：

```json
[
  {
    "image_id": 12345,
    "category_id": 1,
    "bbox": [100, 150, 200, 250],
    "score": 0.95
  }
]
```

边界框格式：`[x_min, y_min, width, height]`（左上角坐标 + 宽高）。

## 模型基线

### Faster R-CNN

- **架构**：ResNet-50 骨干 + FPN（特征金字塔网络）
- **损失**：GIoU loss，提升定位精度
- **预期 AP@0.5:0.95**：验证集约 **0.759**

### Deformable DETR

- **架构**：ResNet-50 骨干 + 可变形注意力
- **训练**：端到端 Transformer 检测
- **预期 AP@0.5:0.95**：验证集约 **0.788**

## 快速开始

### 1. 环境配置

安装 MMDetection 依赖：

```bash
pip install openmim
mim install mmengine==0.10.7 mmcv==2.1.0 mmdet==3.3.0
```

安装评估依赖：

```bash
pip install pycocotools
```

### 2. 训练模型

进入 MMDetection 目录：

```bash
cd mm
```

四卡分布式训练：

```bash
bash tools/dist_train.sh \
  config/faster-rcnn_r50_fpn_giou_20e.py \
  4
```

### 3. 评估模型

生成预测：

```bash
bash tools/dist_test.sh \
  config/faster-rcnn_r50_fpn_giou_20e.py \
  work_dirs/faster-rcnn_r50_fpn_giou_20e/epoch_20.pth \
  4
```

返回资源根目录并评估：

```bash
cd ..
python eval.py \
  --gt data/val.json \
  --pred mm/work_dirs/faster-rcnn_r50_fpn_giou_20e/test.bbox.json \
  --per-class
```

## 注意事项

- 所有配置已针对本数据集优化
- 评估脚本会在最终测试前校验提交格式
- 数据集可视化工具可用于排查标注质量问题
- 提供多种模型架构供对比实验

## 常见问题

| 问题 | 建议 |
|------|------|
| **格式校验** | 最终提交前，务必在验证集上测试预测格式 |
| **类别 ID** | 确保 `category_id` 与数据集标注一致（0–9） |
| **显存不足** | 在配置文件中减小 batch size |
| **路径错误** | 跨目录操作时建议使用绝对路径 |
