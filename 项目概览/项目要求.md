# 挑战赛说明：第一人称视角日常物体检测

## 挑战背景

第一人称（自我中心）视觉与传统第三人称目标检测有明显不同。物体常以非常规角度出现，伴随运动模糊，尺度变化也极大。本任务要求构建一个检测器，在这一困难场景下稳定识别日常物体。

## 数据集

- **总图像数**：13,000 张第一人称视角图像
- **划分**：训练集 10,000 / 验证集 1,000 / 测试集 2,000
- **标注格式**：COCO 风格 JSON，含二维边界框
- **本地路径**：`resource/data/`

### 物体类别

| category_id | 类别 | category_id | 类别 |
|---:|---|---:|---|
| 0 | Pillow | 5 | Mug |
| 1 | Box | 6 | Door |
| 2 | Book | 7 | Shelf |
| 3 | Bottle | 8 | Plate |
| 4 | Chair | 9 | Sofa |

类别与 ID 以 `train.json` 中的 `categories` 为准，验证集与测试集完全一致。

## 评估指标

### 主要指标

主要评估指标为 **mAP@0.5:0.95**（IoU 从 0.50 到 0.95 的平均精度均值）。这是 COCO 标准评估指标：在 0.50 至 0.95 的 IoU 阈值上（步长 0.05）对精度取平均，综合衡量定位准确性与检测置信度。

### 详细指标

除主指标外，还会报告以下指标：

| 指标 | 说明 |
|------|------|
| **mAP@0.5:0.95** | 主排名指标，IoU 0.50–0.95 平均 |
| **mAP@0.5** | 较宽松 IoU 阈值下的检测精度 |
| **mAP@0.75** | 较严格 IoU 阈值下的检测精度 |
| **按物体尺度的 mAP** | 小、中、大目标上的分别表现 |
| **平均召回率（AR）** | 每张图允许 1 / 10 / 100 个检测时的最大召回 |

## 提交格式

提交文件名为 **`submission.csv`**，结构如下：

| 列名 | 说明 |
|------|------|
| **id** | 图像 ID；文件须含 **2,000 行**，每行对应一张测试图像 |
| **predictions** | JSON 数组，包含该图像的全部检测结果 |

`predictions` 列中每条检测须为如下格式：

```json
{
  "image_id": <int>,
  "category_id": <int>,
  "bbox": [x, y, w, h],
  "score": <float>
}
```

字段说明：

- **category_id**：0–9，对应上表 10 个物体类别
- **bbox**：COCO 格式 `[x_min, y_min, width, height]`（左上角坐标 + 宽高）
- **score**：置信度，取值 0–1

完整示例（`predictions` 列内容）：

```json
[
  {
    "image_id": 12345,
    "category_id": 3,
    "bbox": [100, 150, 200, 250],
    "score": 0.85
  }
]
```

**重要**：

- 请使用 **`resource/convert_to_submission.py`** 生成提交文件，确保格式正确
- **不要手动编辑 CSV 文件**
- 竞赛 Rules 中可能写 `submission.json`，但 Evaluation 与官方转换器要求 **CSV**；以官方转换器输出为准
- 无检测结果的图像，`predictions` 应为空数组 `[]`，不可漏掉该图像行

## 可选检测方法

若希望进一步提高挑战难度并拓展学习，可尝试以下前沿检测算法：

- **YOLOv10-N/S**：无 NMS 架构，吞吐高
- **RT-DETRv2-Lite**：轻量 Transformer 检测器
- **RTMDet-tiny/nano**：OpenMMLab 系列轻量模型
- **NanoDet-Plus**：面向移动端的检测器
- **PP-PicoDet / PP-YOLOE**：面向移动端优化的检测模型
- **LW-DETR**：轻量 DETR 替代方案

## 测试与提交

以下命令默认在 `resource/` 目录下执行。

### 步骤 1：生成测试集预测

在测试集上运行推理，生成 `test.bbox.json`。

**Deformable DETR：**

```bash
cd resource/mm
bash tools/dist_test.sh \
  config/deformable-detr_r50.py \
  work_dirs/deformable-detr_r50/epoch_50.pth \
  1
```

**Faster R-CNN：**

```bash
cd resource/mm
bash tools/dist_test.sh \
  config/faster-rcnn_r50_fpn_giou_20e.py \
  work_dirs/faster-rcnn_r50_fpn_giou_20e/epoch_20.pth \
  1
```

预测文件会写入对应 `work_dirs/` 目录，例如 `test.bbox.json`。

### 步骤 2：转换为 Kaggle 提交格式

使用 `resource/convert_to_submission.py`，将 MMDetection 输出转为 CSV。

**推荐用法**（默认读取 `data/test.json`，确保 2,000 张测试图全部包含）：

```bash
cd resource
python convert_to_submission.py \
  --pred mm/work_dirs/deformable-detr_r50/test.bbox.json \
  --output submission.csv
```

**显式指定 test.json：**

```bash
python convert_to_submission.py \
  --pred mm/work_dirs/deformable-detr_r50/test.bbox.json \
  --test data/test.json \
  --output submission.csv
```

**Faster R-CNN 示例：**

```bash
python convert_to_submission.py \
  --pred mm/work_dirs/faster-rcnn_r50_fpn_giou_20e/test.bbox.json \
  --test data/test.json \
  --output submission.csv
```

**其他选项：**

| 参数 | 说明 |
|------|------|
| `--pred` | 预测 JSON 路径（必填） |
| `--output` | 输出 CSV，默认 `submission.csv` |
| `--test` | test.json 路径，默认 `data/test.json` |
| `--images` | 文本文件，每行一个 image ID |
| `--no-test` | 不读 test.json；**不推荐**，可能漏掉无预测的图像 |

**输入格式**（`test.bbox.json`）与 **输出格式**（CSV 每行）：

```json
// 输入：扁平 JSON 数组
[{"image_id": 123, "category_id": 0, "bbox": [x, y, w, h], "score": 0.95}]

// 输出 CSV
id,predictions
123,"[{\"image_id\": 123, \"category_id\": 0, \"bbox\": [x, y, w, h], \"score\": 0.95}]"
456,"[]"
```

**预期输出示例：**

```
Loaded 10310 predictions from mm/work_dirs/faster-rcnn_r50_fpn_giou_20e/test.bbox.json
Loaded 2000 image IDs from data/test.json
Processing 2000 unique images
✓ Saved submission to submission.csv
  - 2000 rows (one per image)
  - 1997 images with predictions
  - 3 images with empty predictions
  - 10310 total predictions
✓ Done! You can now submit submission.csv to Kaggle
```

完整脚本源码见 `resource/convert_to_submission.py`。

### 步骤 3：上传 Kaggle

1. 打开 Kaggle 竞赛页面
2. 点击 **Submit Predictions**
3. 上传 `submission.csv`
4. 在提交说明中填写姓名与学号
5. 点击 **Make Submission**
